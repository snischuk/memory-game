# Memory Game

Classic memory card game built with Vanilla JavaScript, CSS and Vite.

## Features

- Card matching game
- Flip animations
- Move counter
- Leaderboard with `localStorage`
- Victory modal
- Responsive design
- Background music

## Local Setup

```bash
npm install
npm run dev
```

Open the URL shown in the terminal.

## Production

```bash
npm run build
npm run preview
```
